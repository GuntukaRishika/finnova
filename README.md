# Finnova

A frontend foundation for the AI-powered personal finance management platform.

## Week 1 scope
- Create the GitHub repository structure and project foundation
- Set up a React + Vite frontend with Tailwind CSS
- Build the landing page, navbar, footer, and 404 page
- Organize the folders for components, pages, hooks, redux, services, utils, and assets

## Setup
1. Install Node.js and npm
2. Run `npm install`
3. Run `npm run dev`
